## How to Run `install.sh`

1. Open your terminal.
2. Navigate to the directory containing `install.sh`:
    ```sh
    cd /Users/rochellekris/dotfiles
    ```
3. Make sure the script is executable:
    ```sh
    chmod +x install.sh
    ```
4. Run the script:
    ```sh
    ./install.sh
    ```
5. If you make updates to `.profile`, update your profile:
    ```sh
    reload
    ```

    or 
    
    ```sh
    source ~/.profile
    ```
